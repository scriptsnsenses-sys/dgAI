One self-hosted model, two familiar API shapes. Point your app at this service and build with Converse 1.3.

Base URL ● Live

The service loads a quantized Converse 1.3 model from Hugging Face when it starts. The first boot downloads the model; wait for /health to report ready.

Quick start

Both endpoints accept JSON over HTTPS. No API key is required by default; configure a gateway or network-level access control before exposing a production endpoint publicly.

curl /v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "converse-1.3",
    "messages": [
      {"role": "user", "content": "Help me think this through."}
    ],
    "temperature": 0.7,
    "max_tokens": 512
  }'

OpenAI-compatible chat completions

POST/v1/chat/completions

Accepts system, developer, user, and assistant text messages. Returns a chat completion object with choices and token usage. Set stream: true for server-sent events.

{
  "id": "chatcmpl-…",
  "object": "chat.completion",
  "model": "converse-1.3",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "…"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 18, "completion_tokens": 42, "total_tokens": 60}
}

Anthropic-compatible messages

POST/v1/messages

Accepts a top-level system prompt and text messages with user or assistant roles. Responses use the Anthropic message envelope and text content blocks. Set stream: true for message events over SSE.

curl /v1/messages \
  -H "Content-Type: application/json" \
  -d '{
    "model": "converse-1.3",
    "max_tokens": 512,
    "system": "You are a thoughtful writing partner.",
    "messages": [{"role": "user", "content": "Give me a fresh start."}]
  }'

Parameters & limits

TEXT ONLYInput and output

Text messages only; image and audio input, tool calls, and multimodal content are not supported. Content arrays may contain text blocks.

1–2,048Maximum generated tokens

Defaults: temperature 0.7, top_p 0.8, max_tokens 512. Context defaults to 2,048 tokens to reduce memory use and speed startup; prompt and generated text share this context window.

GET/health

Returns loading, ready, or error, plus a phase (downloading or initializing) while loading. Completion endpoints respond with HTTP 503 until the model is ready.

Deployment

Connect this branch to Render as a Blueprint using the included render.yaml. It configures a 4 GB RAM instance and 3 GB persistent disk for the approximately 986 MB Q4_K_M GGUF download from mradermacher/Converse-1.3-GGUF. Both are paid resources and may increase your bill. The community-converted model runs on CPU, so generation speed still depends on the instance.

For an existing manual service, choose a 4 GB RAM instance, attach a 3 GB disk at /var/data, and set HF_HOME=/var/data/huggingface, MODEL_CONTEXT=2048, and MODEL_THREADS=2. The persistent cache prevents repeat downloads, but the initial download still depends on network speed; under a minute is not guaranteed.
